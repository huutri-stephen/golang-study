## How to Use

1. Theo dõi progress tại `checklist/weekly_checklist.md`
2. Mỗi tuần đọc `notes.md` để nắm theory
3. Dùng `flashcards.md` để self-test
4. Chạy code examples để hiểu thực tế
5. Cuối tuần review lại những gì chưa vững
